# Sameer Shaik — Python Developer Portfolio

A responsive, Python-powered portfolio built with Streamlit. It highlights selected Python, data analysis, and machine-learning projects in a mobile-friendly layout.

## Features
- Responsive layout for phone, tablet, and desktop
- Sidebar navigation
- Project cards and category filtering
- Skills and About sections
- Contact links
- Custom CSS styling

## Run locally
1. Install Python 3.10 or newer.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the app:
   ```bash
   streamlit run app.py
   ```



## Deploy
You can deploy this Streamlit app using Streamlit Community Cloud by connecting your GitHub repository and selecting `app.py` as the main file.
