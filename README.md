# Sameer Shaik — Python Developer Portfolio

A responsive, Python-powered portfolio built with Streamlit. It highlights selected Python, data analysis, and machine-learning projects in a mobile-friendly layout.

## Features
- Responsive layout for phone, tablet, and desktop
- Sidebar navigation
- Project cards and category filtering
- Skills and About sections
- Contact links
- Custom CSS styling

## Run locally
1. Install Python 3.10 or newer.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the app:
   ```bash
   streamlit run app.py
   ```

## Before sharing with recruiters
- Edit `app.py` and replace `YOUR-GITHUB-USERNAME` and `YOUR-EMAIL@example.com`.
- Verify every project title, description, repository URL, and project status.
- Do not claim that an unfinished project is complete.
- Add screenshots and individual repository links for projects you have tested.
- Never publish passwords, API keys, private resume details, or sensitive data.

## Deploy
You can deploy this Streamlit app using Streamlit Community Cloud by connecting your GitHub repository and selecting `app.py` as the main file.
